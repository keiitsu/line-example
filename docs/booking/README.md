# LINE 預約互動模板｜獨立 HTML

線上預覽：https://keiitsu.github.io/line-example/booking/

下載 `index.html` 後，以 Chrome、Edge 或 Firefox 直接開啟。不需要 Node.js、網路或 API 金鑰；所有 CSS 與 JavaScript 已包在檔案內。

可體驗服務／日期／時段選擇、姓名與確認、查詢、改期、二次確認取消、兩位顧客搶位、客服案件、配色與示範工作台。

此為前端互動模型：資料只存在當前分頁，重新載入會清除；不同分頁或裝置不共享資料。提醒按鈕只切換示範偏好，不會發送 LINE 訊息或同步 Google Calendar。請使用虛構姓名。

工作台提供紀錄查看與客服結案，正式版的驗簽、資料庫與排程功能不包含在這個離線檔案內。
