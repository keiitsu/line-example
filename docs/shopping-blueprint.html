交付及估價前提

一品牌、一官方帳號、一語言；業主提供核准圖文及可用的測試 API。工時包含模組分析、設定／開發、測試、交接與一輪修正。1 人日＝8 小時，排程採每週 30 小時有效投入；客戶等候、平台審核、採購與異常 API 排查不算承諾交期。多人並行不會自動等比縮短。

本次交付為離線可開啟的互動 HTML 與規劃文件。尚未開通、發布或驗收任何正式 LINE、登入、金流、會員或 CRM。此前模板的關鍵字商品搜尋屬程式能力，重新歸入進階 A13；原生多頁素材不等同即時資料卡片。
